投稿主題

如果你做了一套主題想分享給社群，歡迎開 Pull Request。

  1. 1 Fork chiatom-themes repo
  2. 2 在 themes/ 資料夾新增主題資料夾，命名用 kebab-case（如 my-theme）
  3. 3 確認資料夾內包含 theme.css、theme.json、preview.png
  4. 4 開 Pull Request，說明主題的設計理念和適用場景
開 Pull Request →

主題包規格

提交前請確認符合以下格式，確保主題可以正確匯入 Chiatom。

  • theme.json 需包含 name、version、author、description
  • preview.png 建議尺寸 800×566px（A4 比例）
  • 授權聲明為 MIT，與主 repo 一致
  • 主題 CSS 作用域限制在 .page 容器內，不影響編輯器 UI
